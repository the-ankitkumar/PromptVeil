# Project Rules & Standards (`rules.md`)
## Project Name: Promptveil
### Timeline: 3 Months (~12 Weeks)

---

### 1. MANDATORY ANTIGRAVITY AI INTERACTION PROTOCOL
* **Strict Permission Check**: Antigravity **MUST NEVER** start or complete tasks autonomously without asking Ankit first.
  - At the start of every session, Antigravity must explicitly ask: *"Ankit, which week (Week 1 to Week 12) and specific task should we execute today?"*
* **State & Memory Persistence**: Antigravity must strictly retain and remember all past decisions, modifications, and user instructions across weeks. Any change made in earlier weeks must remain consistent throughout the 3-month roadmap.
* **Simple, Clear Communication**: Antigravity must report progress in simple, direct language—clearly detailing what is being worked on and verifying approvals.

---

### 2. DEVELOPMENT ORDER & TECH ROLES
1. **Phase 1 (Weeks 1–4)**: Frontend Architecture & Flat UI (React.js + Tailwind CSS).
2. **Phase 2 (Weeks 5–8)**: Backend Core, MongoDB, Tri-Layer Hybrid Engine (Node.js + Express.js + Mongoose).
3. **Phase 3 (Weeks 9–10)**: In-Situ Grammarly-Like Browser Extension (Chrome Manifest V3).
4. **Phase 4 (Weeks 11–12)**: Integration, Telemetry Sync, Benchmarking (BIPIA/AgentDojo), & Final Polish.
* **Project Lead / Decision Maker**: Ankit Kumar.

---

### 3. CODE & DESIGN STANDARDS
* **Design Aesthetic**: Pure Flat Design (2D, solid colors, crisp 1px borders, zero heavy shadows).
* **Pure Frontend Scope (Month 1)**: During Month 1, focus is strictly on pure Frontend & Flat UI design. The Navbar includes `Home`, `Scanner`, `Extension`, `Docs`, Theme Switcher, and `Sign In` UI button. Backend database endpoints, live JWT authentication logic, and Threat Logs live data will be wired during Month 2.
* **Unified Input**: Text typing and File upload (PDF/TXT/DOC) must always stay unified in a single, intuitive card.
* **Performance**: Browser extension heuristics must complete within <15ms without blocking the host UI.
